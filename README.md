# LearnMore Connect

CRM for LearnMore Technologies. **Milestones 1–5:** Django/DRF APIs and a responsive Next.js TypeScript workspace for dashboards, contacts, leads, branches, availability, assignments, follow-ups and the shared WhatsApp inbox. The official Meta Cloud API integration defaults to mock mode; live sends require explicit approval and configuration.
